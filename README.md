## Today's Topic is EF Core
### What is EF Core?
EF Core (Entity Framework Core) is an open-source, lightweight, and extensible version of the popular Entity Framework data access technology. It is a modern object-database mapper that enables .NET developers to work with databases using .NET objects. EF Core supports a wide range of database providers, including SQL Server, SQLite, PostgreSQL, MySQL, and more.
